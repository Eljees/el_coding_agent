## 1. Суть проекта (краткое резюме)

`local_codex_lite` — локальный, приватный кодинг-агент MVP под Windows/PowerShell.
Работает против локального vLLM (localhost:8015, qwen25-coder-14b-awq).

Базовый цикл: задача → ранжирование файлов воркспейса → план LLM → unified diff → валидация → превью → (--apply) git apply + бэкап → пост-проверка AST → (--exec) команды → evidence в `.local-codex-lite/runs/<ts>/`.

Приоритеты: безопасность → evidence-first → маленький читаемый core → локальность/приватность.
