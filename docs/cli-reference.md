# CLI reference

Invoke as `python -m local_codex_lite <command>` (or the installed
`local-codex-lite` script).

The day-to-day workflow in four lines:

```powershell
python -m local_codex_lite run "fix the bug in foo.py" --dry-run   # plan + preview, no writes
python -m local_codex_lite run "fix the bug in foo.py" --apply     # actually patch files
python -m local_codex_lite doctor                                  # health check
python -m local_codex_lite logs latest                             # inspect the last run
```

Nothing is written without `--apply`; no command runs without `--exec`.

The command reference below is generated from the real argparse definitions in
`local_codex_lite/cli_parser.py`, so it cannot drift from the code. After
changing the CLI surface, refresh it with:

```powershell
python scripts/gen_cli_reference.py          # rewrite this file
python scripts/gen_cli_reference.py --check  # CI mode: exit 1 if stale
```

Edit only the text outside the markers — everything between them is
overwritten on regeneration.
